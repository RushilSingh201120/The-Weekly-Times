The Weekly Times Application Code Reference
===========================================

Introduction
------------

This section provides technical documentation for the Python modules
that make up The Weekly Times Django application.

The reference is generated using Sphinx and extracts documentation
from the docstrings defined throughout the project's source code.

It provides information about the application's classes, functions,
methods, and their responsibilities.

News Application
----------------

The news application contains the core functionality of The Weekly Times.
Its modules are responsible for managing users, articles, newsletters,
permissions, forms, administrative functionality, and API operations.
